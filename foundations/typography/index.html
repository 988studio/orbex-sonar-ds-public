Typography

One superfamily, fourteen roles. The interface is dense with figures, so sizes stay small and steady; hierarchy comes from weight and color more than from size.

Families

  • Orders, deliveries and stock

    IBM Plex Sans

    Every interface text.

    --sonar-font-family-sans

  • Mo Tu We Th Fr Sa Su

    IBM Plex Sans Condensed

    Weekday initials and the wordmark, where width is scarce.

    --sonar-font-family-condensed

  • 2,000 1,500 1,000

    IBM Plex Mono

    Chart axes and navigation overlines.

    --sonar-font-family-mono

Roles

Names follow Material 3: headline, title, body and label, from larger to smaller and from reading to scanning. Two roles are Sonar-DB’s own: caption for units in pills and data for chart axes. Each role is a font shorthand plus its tracking.

In code

Use the class for markup you control, or the two custom properties inside a component’s styles.

css 
@import '@orbex/sonar-tokens/type.css';

<h2 class="sonar-type-title-lg">Daily shipments</h2>

/* or, inside a component */
.card-title {
  font: var(--sonar-type-title-lg);
  letter-spacing: var(--sonar-type-title-lg-tracking);
}

Guidelines

  • Join a figure and its unit with a non-breaking space, 1,420&nbsp;plt, so they never wrap apart.
  • Use color, not size, to step down: a tertiary date next to a strong figure reads as secondary at the same size.
  • Keep uppercase to the two roles that define it. Everything else is sentence case.
  • Titles are short nouns (Orders, Daily shipments). Actions are verbs (Create order, Release stock).
