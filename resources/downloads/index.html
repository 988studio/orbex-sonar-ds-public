Resources / Downloads

Downloads

The files the packages publish, at version 1.1.4, to open or link to without installing anything. In an app, import them from the packages instead, so they update with the version.

Files

  • CSS tokens.css

    Every token as a CSS custom property, light and dark, in the sonar.tokens layer. 272 tokens.

    @orbex/sonar-tokens/tokens.css

  • CSS type.css

    The type roles as classes, for markup that is not a component.

    @orbex/sonar-tokens/type.css

  • JSON tokens.json

    Every token resolved in each theme, with its CSS variable, description and reference: for design tools and scripts.

    @orbex/sonar-tokens/tokens.json

  • JSON api.json

    The props of every component part (35 parts), with types, defaults and descriptions, read from the source at build time.

    @orbex/sonar-components/api.json

  • JSON sizes.json

    The gzipped weight of each entry point, script and styles, with its budget.

    @orbex/sonar-components/sizes.json

  • Text llms.txt

    The system for language models and coding agents: every page, and the API of every component.

    llmstxt.org
