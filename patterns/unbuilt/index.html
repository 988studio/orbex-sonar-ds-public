Unbuilt modules

A section in the navigation that has no screen yet opens this page instead of a dead link: a 404 that says what happened, lists what does work and leads back to the Overview.

Try it

Choose any sidebar section other than Overview, or one of the Support links. The chips open the sections that work; Customize overview opens its sheet; Back to Overview, or Overview in the sidebar, returns.

Anatomy

  • Code: “404 · Prototype”, small, above the title.
  • Title: the section’s name, as the sidebar says it, and that it isn’t built: “Orders isn’t part of this prototype”.
  • Explanation: one sentence on why, and where the interactions are.
  • What works: the sidebar options that work, as chips that go there, and the rest as a list.
  • Way back: Back to Overview, the one filled button.

Rules

  • Every entry in the navigation leads somewhere. A section without a screen gets this page, never an empty one or a link that does nothing.
  • The sidebar stays as it is, with the section marked, so people know where they are.
  • In the product the same page serves any module not built yet; change the code line when it is not a prototype.

Accessibility

  • The page is the main landmark, named by its title.
  • The chips and the button are buttons; the list of other things that work is plain text.
