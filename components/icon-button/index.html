Components / Icon button

Icon button

A round button with one icon, for actions people recognize at a glance: notifications, search, more actions. Its name is required, because nothing else on screen says it.

  • Native HTML
  • 1.5 KB gzipped · script and styles
  • @orbex/sonar-components/icon-button

Examples

Sizes, variants and states

Usage

  • Standard in bars and on cards; the other weights follow Button.
  • Give it a Tooltip with the same words as its label, so sighted people can learn it too.
  • When an icon could mean several things, use a Button with a label instead.

Do and don’t

Accessibility

Keyboard

Key What it does
Tab Moves focus to the control, and on.
Enter or Space Activates it.

Roles and attributes

Element or attribute What it gives
aria-label From the required label prop: the button’s name, since it shows no text.
Icon aria-hidden.

Notes

  • label is required and becomes the button’s accessible name.
  • The icon is hidden from assistive technology.
  • On touch screens the hit area grows to 48 px.

Use it

Each component is its own entry point with its own stylesheet, so an app loads only what it uses. The tokens and the cascade layers are set once for the app: see Installation.

tsx 
import { IconButton } from '@orbex/sonar-components/icon-button'
import '@orbex/sonar-components/icon-button.css'

API

Props of IconButton
Prop Type Default
label Required

What the button does, read by assistive technology. Pair the button with a Tooltip to show it on hover.

 string —
icon Required

The icon. Decorative: the label names the action.

 ReactNode —
variant

Standard sits on any surface with no fill; the others follow the weights of Button.

 'standard' | 'filled' | 'tonal' | 'outlined' 'standard'
size

Medium is a 40 px button; small is 32 px, for card headers and dense rows. Both keep a 48 px touch target.

 'small' | 'medium' 'medium'

Also takes every attribute of the native <button> , except children, and a ref to it.
