Components / Tooltip

Tooltip

A short label on the inverse surface, shown on hover and on keyboard focus. Base UI positions it and manages the delays.

  • Behavior from Base UI
  • 1.2 KB gzipped · script and styles
  • @orbex/sonar-components/tooltip

Examples

Sizes, variants and states

Usage

  • A name or a hint, never information someone needs to continue: touch screens show tooltips only on a long press.
  • Wrap a toolbar in a TooltipProvider: once one tooltip is open, the next appears at once.
  • The trigger must be focusable, so keyboard users get the tooltip too.

Do and don’t

Accessibility

Keyboard

Key What it does
Tab Focusing the trigger shows the tooltip, as hovering does.
Escape Hides it.

Roles and attributes

Element or attribute What it gives
Not read separately A tooltip repeats its trigger’s name, such as an icon button’s label, for sighted people. Anything that must be read goes in the name or on the page.

Notes

  • Keyboard focus opens the tooltip without delay; Escape closes it.
  • Text on the inverse surface passes AA in both themes.

Use it

Each component is its own entry point with its own stylesheet, so an app loads only what it uses. The tokens and the cascade layers are set once for the app: see Installation.

tsx 
import { Tooltip, TooltipProvider } from '@orbex/sonar-components/tooltip'
import '@orbex/sonar-components/tooltip.css'

API

Tooltip

A short label on the inverse surface, shown on hover and focus. Wrap groups of triggers in TooltipProvider so that, once one tooltip is open, moving to the next shows it without the delay.

Props of Tooltip
Prop Type Default
content Required

The text shown. Short: a name or a hint, never something the person must read to continue.

 ReactNode —
children Required

The element it describes, usually an IconButton. It must be focusable, so keyboard users get the tooltip too.

 ReactElement —
side

Side of the element the tooltip opens on. It flips when there is no room.

 BaseTooltip.Positioner.Props['side'] 'top'
delay

Time the pointer rests on the trigger before the tooltip opens, in milliseconds. Keyboard focus opens it at once.

 number 300

TooltipProvider

Shares the open delay between tooltips, so moving along a toolbar does not wait at every button.

Passes every other prop to Base UI: see the Base UI reference.
