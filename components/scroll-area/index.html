Components / Scroll area

Scroll area

Content that scrolls inside a fixed height, as the product’s lists do: no scrollbar of the system, a fade at the edge that has more, and a thin indicator that shows while it scrolls and never covers a row or its buttons.

  • Native HTML
  • 2.0 KB gzipped · script and styles
  • @orbex/sonar-components/scroll-area

Examples

Usage

  • For every list that scrolls inside something else: the lists of the optional cards, the bodies of side panels and sheets, the System notifications. The page itself keeps the browser’s scroll.
  • A list stops on its rows, scrolling down or up. In a card, a row that stops at the top lies on the title’s rule, with as much room above its content as below it; the last stop mirrors the first, and every stop shows whole rows. The fades cover only the room inside a row (or between bands), never a row that has stopped.
  • The indicator is 2 px, in the scrollbar color of each theme, never shorter than 32 px. It shows while scrolling and fades out a second after; it flashes for 0.8 s when the pointer or the keyboard arrives, to say there is more.
  • Outside (the default): it runs 4 to 6 px past the end of the area, in the padding of the card or panel around it. Inside: when there is no padding, it takes a 12 px lane at the end of the area, and the content stops before it.
  • Never a system scrollbar over the content: on phones it was drawn over the download buttons, white in dark mode.
  • A card’s own list that gives way first is a Card scroll, built on the same behavior.

Accessibility

Keyboard

Key What it does
Tab Reaches the area only while it scrolls; when everything fits, focus goes straight to its controls.
Up and Down arrows, Page Up and Page Down Scroll the area once it has focus.

Roles and attributes

Element or attribute What it gives
role="group" while scrolling Named by label (“Invoices”), so focus arriving on it says what it is.
Fade and indicator Drawn, aria-hidden; the area’s own scroll position is what assistive technology reads. No system scrollbar is drawn.

Notes

  • While it scrolls, the area is a named group that takes focus, so the arrow keys, Page Up and Page Down scroll it. When everything fits, it adds no tab stop.
  • Label it with what it holds: “Invoices”, “What’s new”.
  • The indicator is decoration, hidden from assistive technology; with reduced motion it appears and goes without fading.

Use it

Each component is its own entry point with its own stylesheet, so an app loads only what it uses. The tokens and the cascade layers are set once for the app: see Installation.

tsx 
import { ScrollArea } from '@orbex/sonar-components/scroll-area'
import '@orbex/sonar-components/scroll-area.css'

API

Props of ScrollArea
Prop Type Default
label Required

What the content is, read when the area takes focus to scroll: “Invoices”, “System notifications”.

indicator

Where the indicator runs. Outside: in the padding beside the area, 4 to 6 px past its end, as in the product’s cards and panels, where there is padding to hold it. Inside: in a lane of its own at the end of the area, which the content never reaches, for an area with no padding beside it.
