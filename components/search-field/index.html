Search field

A search box whose results open under it as people type. Base UI’s Autocomplete provides the behavior; the app does the searching and passes the results, with a status line that says how the text was read.

  • Behavior from Base UI
  • 4.2 KB gzipped · script and styles
  • Shared with Search result
  • @orbex/sonar-components/search

Examples

Usage

  • Always controlled: the app keeps the text and decides the results. Search after a short pause in typing, not on every key.
  • Return true from onItemChoose to keep the list open, as a suggestion that fills the field does.
  • Draw each result with Search result. The whole pattern, with its rules, is in Patterns › Search.
  • In the app’s top bar, use variant="top-bar": no box of its own, it fills the bar’s 39 px search pill with a 22 px icon, 12 px text and an 18 px clear mark, as in the product. On touch screens its text is 16 px drawn at three quarters, so it looks the same and iOS does not zoom in when it takes focus. icon and clearIcon take the app’s own marks.
  • The first result is highlighted whenever the list opens or changes, so Enter takes it at once. Escape clears the text first and keeps the list (now the suggestions); a second Escape closes it.
  • statusIcon draws a mark in the status line’s 28 px accent circle (the sparkle of a smart search). popupClassName, align and popupWidth place and size the results from the app, such as as wide as the pill on a desktop, or the window less 12 px each side on a phone.

Do and don’t

Accessibility

Keyboard

Key What it does
Typing Searches; the list opens under the field with the results, the first one highlighted.
Down and Up arrows Move through the results while focus stays in the field.
Enter Chooses the highlighted result.
Escape Closes the list; again, clears the field.

Roles and attributes

Element or attribute What it gives
role="combobox" on the input With aria-expanded and aria-activedescendant: the highlighted result is read as focus moves, without leaving the field.
role="status" The status line is announced politely: that the search is running, then how the text was read and how many results there are.
aria-busy On the field and the list while results are on their way.
Label Always present for assistive technology, drawn only with showLabel.

Notes

  • The input carries its name itself: while the list is open, the rest of the page is hidden from assistive technology.

Use it

Search field shares its entry point and stylesheet with Search result. The tokens and the cascade layers are set once for the app: see Installation.

tsx 
import { SearchField } from '@orbex/sonar-components/search'
import '@orbex/sonar-components/search.css'
