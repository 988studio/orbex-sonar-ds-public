Components / Chart legend

Chart legend

The key to a chart’s colors: a dot in each part’s tone, then its name, and its value when the chart has none of its own.

  • Native HTML
  • 0.9 KB gzipped · script and styles
  • @orbex/sonar-components/chart-legend

Examples

Usage

  • Under the chart, in the order of the chart’s parts.
  • Hide it from assistive technology when the chart’s name already lists the parts.

Do and don’t

Accessibility

Keyboard

Key What it does
None The legend is text, not a control.

Roles and attributes

Element or attribute What it gives
<ul role="list"> A list of names, read in the order of the chart’s parts.
aria-hidden When the chart’s own name already lists the parts, the legend is hidden so they are not read twice.
Dots Drawn; the name always says what the color stands for.

Notes

  • Every color has a name beside it, so no part depends on telling hues apart.

Use it

Each component is its own entry point with its own stylesheet, so an app loads only what it uses. The tokens and the cascade layers are set once for the app: see Installation.

tsx 
import { ChartLegend } from '@orbex/sonar-components/chart-legend'
import '@orbex/sonar-components/chart-legend.css'

API

Props of ChartLegend
Prop Type Default
items Required

One entry per color, in the order of the chart’s parts.

 ChartLegendItem[] —

Also takes every attribute of the native <ul> , except children, and a ref to it.
