Components / Segmented control

Segmented control

One choice among two to five, drawn as pills on a well: the unit figures are shown in, the view of a list. Native radios underneath.

  • Native HTML
  • 1.9 KB gzipped · script and styles
  • @orbex/sonar-components/segmented-control

Examples

Sizes, variants and states

Usage

  • The choice applies at once. More than five options is a select.
  • Icons only when each icon is unmistakable in its context; every option keeps a label for assistive technology.

Do and don’t

Accessibility

Keyboard

Key What it does
Tab Moves focus to the chosen option.
Arrow keys Move to the next or previous option and choose it.
Space Chooses the focused option.

Roles and attributes

Element or attribute What it gives
<fieldset> and <legend> Group the options under one name, read when focus enters. A hidden legend is still read.
<input type="radio"> One per option: announced as “2 of 3”, with the chosen one checked.
Icons only Each option keeps its label as text for assistive technology.

Notes

  • A <fieldset> named by its legend, with one native radio per option: arrow keys move the choice, Tab leaves the group.
  • The legend can be hidden visually and still names the group.
  • It submits with a form without any script, under its name.

Use it

Each component is its own entry point with its own stylesheet, so an app loads only what it uses. The tokens and the cascade layers are set once for the app: see Installation.

tsx 
import { SegmentedControl } from '@orbex/sonar-components/segmented-control'
import '@orbex/sonar-components/segmented-control.css'
