Components / Card

Card

The unit of the overview: a titled region with one figure that sums it up, its detail and a way to the full page. In the grid it takes one of four heights and scrolls what does not fit between its header and footer.

  • Native HTML
  • 4.8 KB gzipped · script and styles
  • Shared with Card link, Card scroll, Unit menu
  • @orbex/sonar-components/card

Examples

Sizes, variants and states

Usage

  • Size: S, M, L or XL (245, 375, 405 and 535 px) in the overview grid. Without a size, the card follows its content.
  • Summary: one figure with its unit; tone default for figures that are not the card’s main one.
  • Actions: a Unit menu, and nothing else. Footer: a Card link and at most one action.
  • Label: only when the same card shows twice on a page, as on Cards.
  • How the six cards of the overview are composed, and their rules, are in Patterns › Cards.

Do and don’t

Accessibility

Keyboard

Key What it does
Tab Moves through the card’s controls in reading order: unit menu, content, footer.
Unit menu Opens with Enter, Space or Down arrow, like any menu.
Up and Down arrows, Page Up and Page Down On content that scrolls, once it has focus: scroll it. It takes focus only while it scrolls.
Left and Right arrows On the chosen day of a calendar (Deliveries, Payment calendar): the previous or next day. In the month, Up and Down move a week.

Roles and attributes

Element or attribute What it gives
<section aria-labelledby> Each card is a region named by its title, so the overview can be read card by card. Where the same card shows twice, label names each copy: “Orders, size S”.
Unit menu Named with what it shows and what that means: “Unit: plt, Pallets”, so voice control can reach it by its visible text. Its choices are a group of radio items.
Summary bar The bar between label and value is drawn, so it is never read aloud.
role="group" while scrolling Content that scrolls is a group named by its list (“Deliveries of May 12”) or by the card’s title, so focus arriving on it says what it is. The fade and the indicator are drawn and hidden.

Notes

  • The card is a region named by its title, so the overview reads as a list of landmarks.
  • The title’s level follows the page: titleAs="h3" under a page section.

Use it

Card shares its entry point and stylesheet with Card link, Card scroll, Unit menu. The tokens and the cascade layers are set once for the app: see Installation.

tsx 
import { Card } from '@orbex/sonar-components/card'
import '@orbex/sonar-components/card.css'

API

Props of Card
Prop Type Default
title Required

The card’s name, which also names the region for assistive technology.

 ReactNode —
titleAs

Heading level of the title, to fit the page’s outline.

 'h2' | 'h3' 'h2'
actions

Controls at the end of the header, such as a UnitMenu.

 ReactNode —
summary

The figure that sums the card up, under the title: a label and a value, such as Open total and 6,720 plt.

 { label: ReactNode; value: ReactNode; tone?: 'accent' | 'default' } —
footer

The way out of the card, usually a CardLink to the full page.

 ReactNode —
size

Height in the overview grid: S, M, L or XL from the layout tokens. The header and footer stay put; content that does not fit scrolls between them. Without a size the card takes the height of its content.

 's' | 'm' | 'l' | 'xl' —
label

The region’s accessible name, when the title alone would repeat on the page: the same card shown twice, as in “Orders, size S” and “Orders, size M”. By default the title names the region.

 string —

Also takes every attribute of the native <section> , except title, and a ref to it.
