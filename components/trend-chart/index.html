Components / Trend chart

Trend chart

A month day by day as a line, with its running total dotted against a second axis. The legend turns each series off and on; hovering, touching or the arrow keys read a day.

  • Native HTML
  • 4.2 KB gzipped · script and styles
  • @orbex/sonar-components/trend-chart

Examples

Usage

  • One series, and its running total when the month’s sum matters. Days still to come are null and leave the line open.
  • Label three days on the axis: the first, the middle and the last.
  • The width follows its container; the height is a prop.

Do and don’t

Accessibility

Keyboard

Key What it does
Tab Reaches the chart and then its legend buttons.
Left and Right arrows Read the previous or next day.
Home and End Go to the first day or the last day with data.
Escape Clears the day being read.
Enter or Space On a legend button: shows or hides that series.

Roles and attributes

Element or attribute What it gives
role="group" Named by its label, with a hint to use the arrow keys.
aria-live="polite" Reads the chosen day: “May 12: 350 plt, 4,485 plt so far”.
aria-pressed Legend buttons say whether their series is shown.

Notes

  • The chart is a group with a live region: the day being read is announced with both values.

Use it

Each component is its own entry point with its own stylesheet, so an app loads only what it uses. The tokens and the cascade layers are set once for the app: see Installation.

tsx 
import { TrendChart } from '@orbex/sonar-components/trend-chart'
import '@orbex/sonar-components/trend-chart.css'
