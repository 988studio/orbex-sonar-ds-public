Components / Tick bar

Tick bar

A share of a whole as one row of fine ticks, each part in its share of the width and in its chart role. The parts meet without a gap, and no tick is ever split between two colors.

  • Native HTML
  • 1.3 KB gzipped · script and styles
  • @orbex/sonar-components/tick-bar

Examples

Usage

  • Two or three parts of one whole. The first in accent, then strong, the rest in muted; danger only for an alert.
  • A Chart legend under it names the colors; the card states the figures in text.
  • Give it a label and a format: they make its accessible name.

Do and don’t

Accessibility

Keyboard

Key What it does
None A tick bar is a picture; the card states its figures in text.

Roles and attributes

Element or attribute What it gives
role="img" with aria-label One name lists every part with its value: “May orders: Shipped 1,420 plt, On hold 80 plt, Pending 1,100 plt”.
Ticks Drawn in CSS, so they are never read one by one.

Notes

  • One name lists every part with its value, so the bar is read once, whole.

Use it

Each component is its own entry point with its own stylesheet, so an app loads only what it uses. The tokens and the cascade layers are set once for the app: see Installation.

tsx 
import { TickBar } from '@orbex/sonar-components/tick-bar'
import '@orbex/sonar-components/tick-bar.css'
