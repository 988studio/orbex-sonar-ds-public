Components / Card scroll

Card scroll

The part of a card’s content that gives way first when the card’s size leaves no room: it keeps its full height while it fits, and scrolls when it does not, while the rest of the card stays in place.

  • Native HTML
  • 4.5 KB gzipped · script and styles
  • Shared with Card, Card link, Unit menu
  • @orbex/sonar-components/card

Examples

Usage

  • Wrap the list that can give way: the deliveries of a day, the products to reorder. Never the summary or a chart.
  • One per card. If it is not enough, the card’s whole content scrolls as well.
  • No scrollbar: a fade at the edge that has more, and a thin indicator while scrolling.
  • Label it with what the list is: “Deliveries of May 12”.

Do and don’t

Accessibility

Keyboard

Key What it does
Tab Reaches the list only while it scrolls; when everything fits, focus goes straight to its controls.
Up and Down arrows, Page Up and Page Down Scroll the list once it has focus.

Roles and attributes

Element or attribute What it gives
role="group" while scrolling Named by label (“Deliveries of May 12”), so focus arriving on it says what it is.
Fade and indicator Drawn, aria-hidden; the list’s own scroll position is what assistive technology reads.

Notes

  • It takes focus only while it scrolls, so a list that fits adds no tab stop.

Use it

Card scroll shares its entry point and stylesheet with Card, Card link, Unit menu. The tokens and the cascade layers are set once for the app: see Installation.

tsx 
import { CardScroll } from '@orbex/sonar-components/card'
import '@orbex/sonar-components/card.css'
