Components / Ring chart

Ring chart

Parts of a whole as a ring of ticks, 96 by default. The hole can hold the total; the parts run clockwise from the top, or counterclockwise toward a figure on their left.

  • Native HTML
  • 1.4 KB gzipped · script and styles
  • @orbex/sonar-components/ring-chart

Examples

Usage

  • Two or three parts of one whole, never values over time.
  • Set the width with CSS; the ring scales.
  • direction="counterclockwise" when the first part’s figure sits on the left, as in Inventory.

Do and don’t

Accessibility

Keyboard

Key What it does
None A ring is a picture; the figures beside it carry the values.

Roles and attributes

Element or attribute What it gives
role="img" with aria-label One name lists every part with its value, written by format.
Content in the hole Read after the name, when it adds to it, such as a total.

Notes

  • One name lists every part with its value, written by format.

Use it

Each component is its own entry point with its own stylesheet, so an app loads only what it uses. The tokens and the cascade layers are set once for the app: see Installation.

tsx 
import { RingChart } from '@orbex/sonar-components/ring-chart'
import '@orbex/sonar-components/ring-chart.css'

API

Props of RingChart
Prop Type Default
segments Required

The parts of the whole, in order around the ring: each with a label, a value and a chart tone.

 ChartSegment[] —
label Required

What the ring measures, read before its parts: “Inventory”.

 string —
ticks

Ticks around the ring. Fewer read as coarser; the dashboard uses 96.

 number 96
format

Writes a value for the chart’s accessible name: “On hold 1,420 plt”. Plain numbers when left out.

 (value: number) => string —
direction

Which way the parts run from twelve o’clock. Counterclockwise puts the first part on the left, beside a label set on that side, as in the Inventory card.

 'clockwise' | 'counterclockwise' 'clockwise'
children

Content in the hole of the ring, such as the total.
