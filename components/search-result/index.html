Components / Search result

Search result

One row of results: an icon for the kind of thing, a title, a line under it with the kind and the day, and its state at the end.

  • Behavior from Base UI
  • 4.2 KB gzipped · script and styles
  • Shared with Search field
  • @orbex/sonar-components/search

Examples

Usage

  • Return it from the search field’s renderItem; the field makes it an option of its list.
  • Title: the code and its key figure. Description: the kind and the day. Trailing: a Status, in words.

Do and don’t

Accessibility

Keyboard

Key What it does
None A result is chosen through the search field: arrows and Enter.

Roles and attributes

Element or attribute What it gives
role="option" Each result is an option of the list, read by its text.
Icon aria-hidden: the description says what kind of result it is.
Trailing Status Read after the description, in words.

Notes

  • The icon is hidden; the description already says what kind of result it is.

Use it

Search result shares its entry point and stylesheet with Search field. The tokens and the cascade layers are set once for the app: see Installation.

tsx 
import { SearchResult } from '@orbex/sonar-components/search'
import '@orbex/sonar-components/search.css'
