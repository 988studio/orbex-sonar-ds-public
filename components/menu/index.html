Components / Menu

Menu

A list of actions in a popup that grows from its trigger. Base UI provides the behavior: focus, arrow keys, typeahead, dismissal and positioning away from the window edges.

  • Behavior from Base UI
  • 2.0 KB gzipped · script and styles
  • @orbex/sonar-components/menu

Examples

Sizes, variants and states

Usage

  • For actions on the thing in view. Choices that change what is shown can live in a menu as a radio group.
  • Destructive actions go last, after a separator, in the danger tone. They still need a confirmation or an undo.
  • The trigger keeps its look: pass a Button or an IconButton with render.

Do and don’t

Accessibility

Keyboard

Key What it does
Enter, Space or Down arrow On the trigger: opens the menu and focuses the first item.
Up and Down arrows Move between items; disabled items are skipped.
Home and End Go to the first or the last item.
A letter Moves to the next item that starts with it.
Enter or Space Activates the item, or chooses it in a group of choices.
Escape Closes the menu and returns focus to the trigger.
Tab Closes the menu and moves on.

Roles and attributes

Element or attribute What it gives
aria-haspopup, aria-expanded On the trigger: it opens a menu, and whether it is open.
role="menu" The popup; items are menuitem, or menuitemradio with aria-checked in a group of choices.
Group labels Name their group, read when focus enters it.

Notes

  • The trigger announces that it opens a menu, and whether it is open.
  • Arrow keys move between items, typing jumps to an item, Escape closes and returns focus to the trigger.
  • The highlight stays neutral behind danger items, so their red text keeps 4.5:1.

Use it

Each component is its own entry point with its own stylesheet, so an app loads only what it uses. The tokens and the cascade layers are set once for the app: see Installation.

tsx 
import { Menu } from '@orbex/sonar-components/menu'
import '@orbex/sonar-components/menu.css'

API

Menu.Root

Holds the menu’s open state.

Passes every other prop to Base UI: see the Base UI reference.

Menu.Trigger

The element that opens the menu. Pass a Button or an IconButton with render, so the trigger keeps its look.

Passes every other prop to Base UI: see the Base UI reference.

Menu.Content

The popup, positioned against the trigger and rendered at the end of the document.
